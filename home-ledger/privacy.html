Home Ledger privacy policy

Home Ledger is a private app used only by the household that runs it. Its data is stored on that household's own home server and phones.

Gmail data

With the user's permission, Home Ledger reads the user's Gmail (read-only) to find purchase receipts. It searches for likely receipts, reads only those messages, and stores the receipt details (merchant, date, items, amounts) on the household's home server. For other messages it keeps only the message ID, so they are not read again.

To read a receipt, its text may be sent to the AI services the household has configured (OpenAI, Microsoft Azure AI Document Intelligence). Nothing is sent anywhere else.

Home Ledger's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to find and record the user's receipts. It is not sold, not used for advertising, not used to train AI models, and not shared with anyone except as described above.

Bank data

Bank transactions come through Plaid and are stored on the household's home server.

Removing access

Gmail access can be removed at any time at myaccount.google.com/permissions. Deleting the data on the home server removes everything Home Ledger stored.
